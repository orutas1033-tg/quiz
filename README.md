# 一問一答クイズアプリ（Phase 3：PWA版）

CSV / Excel を読み込んで「一問一答（○×自己採点）」と「4択クイズ」を出す個人用の学習アプリです。
**PWA化**したので、配信すればスマホの**ホーム画面に追加**でき、**オフラインでも起動**します。
読み込んだデータはすべて端末内だけで処理され、外部に送信されません。

---

## 1. フォルダ構成

```
quiz-app/                 … すべて同じ階層（フォルダなし＝アップロードが簡単）
├── index.html            … アプリ本体
├── manifest.json         … PWAの設定（アプリ名・アイコン等）
├── sw.js                 … サービスワーカー（オフライン用キャッシュ）
├── papaparse.min.js      … CSV解析（同梱）
├── xlsx.full.min.js      … Excel解析（同梱）
├── icon-192.png / icon-512.png      … アプリアイコン
├── apple-touch-icon.png             … iOSホーム画面用アイコン
├── .nojekyll             … GitHub Pages用のおまじない（空ファイル）
├── sample.csv            … 動作確認用サンプル
├── README.md
└── DEPLOY.md             … 公開手順
```

> **重要**：このアプリは `file://`（ファイルを直接ダブルクリック）では
> サービスワーカーが動かず、オフライン機能とホーム画面追加が使えません。
> **必ず http(s) で配信**してください（下記）。

## 2. ローカルで試す（Mac）

ターミナルでこのフォルダに移動し、簡易サーバーを立てます。

```bash
cd quiz-app
python3 -m http.server 8000
```

- `python3 -m http.server 8000`
  …Python標準の簡易Webサーバーを **8000番ポート** で起動するコマンド。
  追加インストール不要で、このフォルダを `http://localhost:8000` として配信します。

ブラウザで **http://localhost:8000/** を開けば動きます。
（サーバーを止めるにはターミナルで `Ctrl + C`）

> ブラウザの「開発者ツール → Application → Service Workers」で、
> `sw.js` が登録されていれば成功です。一度読み込めば、機内モードでも起動します。

## 3. iPhone でホーム画面に追加する

ホーム画面追加は **https で配信されたページ**で行います（次の Phase 4 で公開）。
公開後の手順は次のとおりです。

1. iPhone の **Safari** で公開URLを開く
2. 共有ボタン（□から↑のアイコン）→「**ホーム画面に追加**」
3. 追加されたアイコンから起動すると、アドレスバーの無い**アプリ風の全画面**で動きます
4. 一度オンラインで開いていれば、以後は**オフラインでも起動**します

## 4. データ（CSV / Excel）の形式

1行目は見出し行。列名は日本語/英語を自動認識します（見つからなければ左から1・2列目を問題・答えに）。

| 列の役割 | 見出し名の例 | 必須 | 表示位置 |
|---|---|---|---|
| 問題 | `問題` `問` `question` `Q` | ◯ | 上部 |
| 答え | `答え` `解答` `answer` `A` | ◯ | 解答エリア |
| カテゴリ | `カテゴリ` `分類` `category` | 任意 | タグ＋絞り込み |
| ヒント | `ヒント` `hint` | 任意 | 問題と一緒 |
| 備考 | `備考` `解説` `補足` `note` | 任意 | 答えの下 |
| 誤答選択肢 | `誤答1` `誤答2` `誤答3`（`ダミー1`…等も可） | 任意 | 4択の誤答 |

**誤答選択肢カラムについて（任意の追加オプション）**
- `誤答1` `誤答2` `誤答3` のように最大3つ用意すると、**4択モードでその行はその誤答を使います**。
- 認識される見出し名：`誤答` `誤答選択肢` `ダミー` `不正解` `distractor` `wrong` `decoy`（末尾に 1〜3 の番号可）。
- 用意した誤答が3つに満たない行は、不足分を他問の答えから自動補充します。
- 誤答カラムが無い行・無いCSVは、**従来どおり他問の答えから自動生成**します（＝完全な追加オプション）。
- これらが効くのは「問題→答え」を問う向きのときです（向きを「答え→問題」にした場合は自動生成になります）。

文字コードは **UTF-8** 推奨。Excel は先頭シートを読み込みます。

## 5. 機能（このバージョン）

- **複数のクイズCSVを保存・切り替え**（IndexedDB に端末内保存）
  - 追加したCSV/Excelは「保存済みクイズ」として一覧に残り、次回起動時もそのまま使えます
  - 各クイズは **名前変更・削除** が可能（削除は確認あり）
  - データは端末内のみ・外部送信なし。ブラウザのデータ消去で消えます
- 2モード：**自己採点（○×）** ／ **4択クイズ**（選んだ時点で確定→解答＋備考を表示）
- 4択の誤答択は他問の答えから自動生成（正解と同一・重複は除外、不足時は全体から補充）
  - **CSVに `誤答1〜3` カラムを用意した行は、その誤答を優先**（追加オプション。不足分は自動補充）
- **問題数の指定**（ランダム出題＝N問おまかせ／番号順＝何番目からN問）
- **ランダム出題は「おまかせ順」**：未回答を優先し、その次は**最終回答が古い問題**を優先
  - まんべんなく一周し、その後は「しばらく解いていないもの」が出やすくなります
  - 各問題に**最終回答日時**を記録（未回答は記録なし）。同条件はシャッフルで偏りを防止
- **間違い記録で出題範囲を限定**（CSVごとに保存）
  - **ミス**：直近（最新）の回答が不正解の問題
  - **うろ覚え**：直近3回に1回以上不正解の問題（ミスを含む広い集合）
  - 問題は内容ではなく**行インデックス（並び順）**で識別。各問題は**直近3回分**だけ記録（累積で重くならない）
- 出題の向き（問題→答え／答え→問題／ランダム）、カテゴリ絞り込み
- 回答中の **「やめる」**（スタート画面に戻る）
- 正答率の表示、**間違えた問題だけもう一周**
- **PWA**：ホーム画面追加・オフライン起動

## 7. アプリを更新したときの注意

`index.html` や `lib/` を差し替えたら、**`sw.js` の `CACHE = "quiz-app-vN"` の
バージョン番号を上げて**ください（例：`v2` → `v3`）。古いキャッシュが破棄され、
新しい内容が読み込まれます。番号を上げ忘れると、古い画面が表示され続けることがあります。

## 8. 保存データ（保存済みクイズ）について

- 保存先は端末内の **IndexedDB**。外部には送信されません。
- **ブラウザ・端末ごと**に保存され、別端末とは同期されません。
- ブラウザの「サイトデータ削除」を行うと消えます。
- iPhoneで「ホーム画面に追加」したPWAは、Safariとは**別の保存領域**を持つことがあります。
  ホーム画面アプリ側で追加したクイズは、その中で保持されます。

### 間違い記録について
- 回答するたびに、各問題の**直近3回分の正誤**がそのクイズ（CSV）に保存されます。
- 問題の識別は**内容ではなく行インデックス（並び順）**です。同じ内容の問題があっても混同しません。
- スタート画面の「出題範囲」で **ミス／うろ覚え** に限定でき、選択肢の横に該当数が出ます。
  - **ミス**＝最新の回答が不正解／**うろ覚え**＝直近3回に1回以上不正解
- 復習で正解し続けると、`○○○`（3回連続正解）でどちらの対象からも自然に外れます。
- ※CSVを編集して**入れ直す**と新しいクイズ（別物）として保存され、記録は引き継がれません（行インデックスがずれるため）。
